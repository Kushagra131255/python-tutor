# LeetCode Solutions in C++

A growing collection of individual C++ solutions, with difficulty, approach, and time/space complexity.

## Layout
- `solutions/0001-two-sum.cpp` — one standalone solution per problem
- Filenames use the LeetCode problem number and a short slug.

## Conventions
- C++17-compatible solutions using the standard library.
- Each file includes a short problem summary, approach, and complexity.
- LeetCode's expected `class Solution` interface is retained where applicable; submit each file separately on LeetCode.
- These are independently written learning solutions. Problem statements are summarized, not copied.

## Progress
- [x] 0001–0031 — solutions committed
- [ ] 0032–0600 — not yet added

## Compile locally
Most files can be compiled after adding a small test harness that calls the method, because LeetCode supplies the driver code. Linked-list solutions rely on LeetCode's provided `ListNode` definition.

Progress indicates files committed, not that every solution has been run against all edge cases. Add and run tests as the collection grows.
